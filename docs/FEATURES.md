# Qadam — возможности

Скриншоты сняты на демо-данных (`SEED_DEMO=true`) в разрешении 1440×900 @2x, мобильные — 390×844 @2x.
Роли: **Алия** — администратор, **Ерлан** — руководитель, **Айгерим** — участник.

## 1. Вход

Вход по почте и паролю. В dev-сборке под формой список демо-аккаунтов (клик подставляет логин и пароль).

![Вход](screenshots/01-login.png)

Тема берётся из настроек системы; тёмная:

![Вход, тёмная тема](screenshots/01-login-dark.png)

## 2. Звонок

Новая встреча: начать аудиозвонок (LiveKit) или сразу загрузить запись. Справа — звонки, которые идут сейчас.
Если LiveKit не настроен, страница предупреждает и оставляет путь через загрузку записи.

![Звонок](screenshots/02-call-start.png)

## 3. Встречи

Список встреч: автор, время, статус обработки, сколько предложений ждут проверки.

![Встречи](screenshots/03-meetings.png)

Страница встречи: транскрипт с таймкодами и спикерами, сводка, что ИИ пропустил и почему, статусы предложенных задач.

![Встреча](screenshots/04-meeting-detail.png)

Если транскрипта нет (звонок не записался, ошибка распознавания) — загрузка аудио или вставка текста вручную (F4 AC2). Доступно автору встречи и руководителю.

![Ручная загрузка](screenshots/05-meeting-upload-fallback.png)

## 4. Проверка предложений ИИ (F6)

Каждое предложение — карточка: название, критерии готовности, исполнитель и срок (если их не сказали — «не указан», ИИ их не выдумывает), цитата из встречи. Пока человек не принял решение, задачи нет ни в бэклоге, ни на доске.

![Проверка](screenshots/06-review-queue.png)

Перед принятием предложение можно отредактировать:

![Редактирование предложения](screenshots/07-review-edit.png)

## 5. Бэклог (F1)

Только принятые задачи и задачи, созданные вручную. Видно, откуда задача пришла.

![Бэклог](screenshots/08-backlog.png)

Карточка задачи (F3): статус, исполнитель, срок, ссылка на встречу и цитату, история изменений с автором и временем.

![Карточка задачи](screenshots/09-task-detail-history.png)

## 6. Доска

Канбан с перетаскиванием. Задачи, пришедшие со встречи за последние сутки, отмечены полосой слева.

![Доска](screenshots/10-board.png)

## 7. Профиль

Меню пользователя: почта, смена пароля, выход.

![Меню пользователя](screenshots/11-user-menu.png)

Смена пароля завершает все остальные сессии пользователя.

![Смена пароля](screenshots/12-change-password.png)

## 8. Команда и роли (F7, только администратор)

Пользователи, роли, статус доступа. Описание ролей — сверху.

![Команда](screenshots/13-team.png)

Новый пользователь: имя, почта, роль, временный пароль.

![Новый пользователь](screenshots/14-team-add-user.png)

Действия над пользователем: изменить данные и роль, задать пароль, отключить доступ (сессии завершаются сразу). Последнего администратора понизить или отключить нельзя.

![Действия](screenshots/15-team-user-actions.png)

## 9. Что видит участник (RBAC)

Участник видит предложения ИИ, но не может их принять или отклонить:

![Проверка у участника](screenshots/16-member-review-readonly.png)

Чужую задачу (не он исполнитель и не он автор) участник открывает только на чтение:

![Чужая задача](screenshots/17-member-task-locked.png)

Раздел «Команда» скрыт из меню; прямой переход по ссылке показывает отказ. API в любом случае отвечает 403.

![Нет доступа](screenshots/18-member-team-forbidden.png)

| Действие | Участник | Руководитель | Администратор |
| --- | :-: | :-: | :-: |
| Смотреть встречи, предложения, задачи | ✓ | ✓ | ✓ |
| Создавать встречи и задачи, подключаться к звонку | ✓ | ✓ | ✓ |
| Загружать запись / текст, пересоздавать черновики, завершать звонок | свои встречи | любые | любые |
| Менять задачи и двигать на доске | свои | любые | любые |
| Принимать / менять / отклонять предложения ИИ | — | ✓ | ✓ |
| Управлять пользователями и ролями | — | — | ✓ |

## Не попало на скриншоты

- **Экран идущего звонка** — нужен запущенный LiveKit + Egress (`docker compose up livekit egress redis`) и микрофон.
- **Статус «Обработка»** во время распознавания Whisper — длится секунды на демо-тексте.
